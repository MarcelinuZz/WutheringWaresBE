Install Guide untuk PocketLog Microservices
==========================================

Prasyarat:
----------
1. Pastikan Docker dan Docker Compose (versi 2.22+) sudah terinstal di komputer Anda (Docker Desktop disarankan).
2. Jika ada, konfigurasi file `.env` di masing-masing folder microservice sesuai kebutuhan (misal: isi kredensial Midtrans, Google OAuth, Discord, SMTP, dll). File `.env` akan dibaca otomatis.
   *Catatan: Variabel untuk DB_HOST dan URL antar service (seperti TOKEN_SERVICE_URL) akan di-override otomatis oleh docker-compose, jadi tidak perlu pusing memikirkan localhost.*

Cara Menjalankan:
-----------------
Buka terminal atau command prompt di root folder proyek ini (sejajar dengan file `docker-compose.yml`), lalu jalankan:

    docker compose watch

Perintah di atas akan:
1. Mem-build dan menjalankan semua 7 microservices beserta 1 database MySQL.
2. Menginisialisasi tabel database `wuthering_wares` beserta akun admin awal secara otomatis.
3. Mengaktifkan *watch mode*. Setiap perubahan pada source code di lokal akan otomatis di-sinkronisasikan ke dalam container dan server akan di-restart otomatis (Hot Reload).

Untuk menghentikan semua service, tekan `Ctrl + C` di terminal tersebut.
Untuk membersihkan dan menghapus semua container beserta data database (jika ingin di-reset ulang), jalankan perintah:

    docker compose down -v
